# 版本发布流程

## 测试版验收

修改功能后，先运行改动相关的测试模块，避免每次都跑全量测试：

```powershell
python -m unittest tests.test_app_root
```

把示例模块替换为本次改动对应的测试模块；涉及多个模块时可一次列出多个测试模块。然后构建测试版，**只覆盖 `dist/football_analysis_test.exe`，不要覆盖正式版**：

```powershell
# 按项目现有本地构建命令生成测试版
# 输出：dist/football_analysis_test.exe
```

运行测试版并由用户完成实际验收。测试版通过后，再进入正式版本流程。提交或发布前仍运行全量测试：

```powershell
python -m unittest discover -s tests
```

截至 2026-11-05 的本地基线：506 项全量测试约 22 秒。若单次明显变慢，先看具体失败和耗时测试，不要默认增加并行度。

## 正式发布

测试版验收通过后，先确认工作区中没有不相关改动，再运行版本升级与全量测试：

```powershell
python tools/release.py 1.18
```

版本升级完成后，构建正式版 `dist/football_analysis.exe`，不要把测试版文件改名充当正式版。确认正式版构建成功后，提交源码并推送版本 tag，触发 GitHub Actions：

```powershell
git add <本次发布文件路径>
git commit -m "发布(1.18): 简述"
git tag v1.18
pwsh -File tools/push_release_retry.ps1 -Tag v1.18
```

正式 exe、更新器、安装包、完整包和 Release 资产由 `.github/workflows/release.yml` 构建发布；不需要在本机重复构建正式资产。只有需要本地验收 exe 时才额外打包。2026-11-05 基线：主程序 PyInstaller 构建约 38 秒，上次 Release workflow 约 1 分钟；更新器和安装器的本地耗时尚未单独测量。

Workflow 已把构建和 Release 上传拆成两个 job，并将五个发布资产暂存 30 天。上传阶段网络失败时，优先在 Actions 中只重跑 `publish` job，可复用本次已构建的 artifact。也可以用 `workflow_dispatch` 输入已有 tag（例如 `v1.18`）重跑；这种方式会重新构建资产，但不需要重新升级版本号或创建新 tag。确认/创建 Release 和资产上传都按 15/30/60/120 秒退避重试，最多 5 次；部分成功的资产通过 `--clobber` 覆盖。

本地推送脚本将分支和 tag 合并为一次 `git push`，短暂超时会自动重试；认证、权限、保护分支和非快进等确定性错误会立即停止。若分支已成功推送但 tag 推送失败，重新运行同一命令即可，Git 会跳过已完成部分。

GitHub Release 资产校验完成后，可删除该版本专属的 `build/release-v<版本>-*` 临时目录和日志；不要批量清理整个 `build/`，其中还包含测试夹具及其他待用产物。

版本升级前先保留当前可交付版本，避免新版本打包失败后无法回退。

```powershell
python tools/release.py 1.3.36
```

`release.py` 会在修改源码版本号前自动把 `dist/` 中已有的发布文件归档到：

```text
dist/history/football_analysis_v<旧版本>_<时间>.zip
```

归档内容包括主程序、更新器、安装包、完整包、`latest.json` 和必要的抓取工具脚本；运行缓存、数据库、报告和 `history` 目录本身不会打进归档。

也可以单独执行归档：

```powershell
python tools/archive_release.py
```

如果是第一次发布、`dist/` 还没有可交付文件，版本同步会提示并跳过归档。

设置中的版本升级优先使用普通发布链接。默认更新清单访问失败时，通过 GitHub Releases API 下载 `latest.json`；安装包下载重试失败时，按原安装包所属的发布标签查找同一资源，通过 API 重试下载。两条下载通路都校验清单中的 SHA-256，失败时不会安装，也不会改下 ZIP 包。公开资源无需用户配置 GitHub Token；API 下载仍可能跳转到文件服务器，其可达性受本地网络影响。

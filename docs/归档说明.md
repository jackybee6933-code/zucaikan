## 现役功能

1. 自动解析胜负彩最新开售期并采集场次，也可用 `--issue` 指定历史期。
2. 解析欧赔、亚洲盘让球和大小盘，输出模型与市场融合推荐。
3. 只跟踪亚洲盘让球初盘到即时盘的变化。
4. 对升盘、降盘、水位反转和水位摆动生成“变盘异动提醒”。
5. 输出浏览器 HTML 页面。(`report.py` 里仍有 `write_csv` / `write_json`，但未被 `write_report_files()` 调用)。
6. 把每期亚洲盘让球异动写入本地 SQLite，可用 `query` 命令或浏览器查询页检索。
7. Windows 独立版 exe 运行结束后自动打开 HTML 报告。

## 使用入口

源码运行：

```powershell
cd C:\path\to\football-analysis-mvp
python run.py --cache-dir cache
```

查询已入库异动：

```powershell
python run.py query --serve
```

不传 `--issue` 即自动抓取最新一期；指定历史期时再加期号，例如：

```powershell
python run.py --issue 26120 --cache-dir cache
```

独立版运行（缺省同样自动抓取最新一期）：

```powershell
.\dist\football_analysis.exe
```

独立版默认在 exe 同目录创建 `cache/` 和 `reports/`。加 `--no-open` 可关闭自动打开浏览器。

从正式归档包解压后运行：

```powershell
.\football_analysis.exe
```

自动模式下，胜负彩列表、竞彩列表和 `odds.xml` 不读取旧缓存；显式指定 `--issue` 时才允许复用这些当前快照缓存。

## 重要边界

- Nowscore“赛前指数”是默认公司初盘与抓取时刻即时盘的快照，不是完整逐笔时间线。
- 需要观察两小时变化时，应在不同时间运行并保留各次 HTML/JSON 报告；当前原型没有后台定时任务。
- `odds.xml`、竞彩列表和球队页主要是当前快照，历史期号的市场覆盖率可能下降。
- 低水和盘口变化属于启发式提示，模型结果仅供研究，不构成投注建议。
- 尚未完成长期赛后回测、命中率评估、数据质量监控和正式部署。
